# Documentación de Empuje y Tracción

Archivos previstos:

- `Instrucciones_Empuje_Traccion.docx`: documento maestro editable.
- `Instrucciones_Empuje_Traccion.pdf`: versión publicada y enlazada desde el programa.

Para actualizar las instrucciones sin modificar el código:

1. Editar el archivo Word.
2. Exportarlo a PDF.
3. Mantener exactamente los mismos nombres de archivo.
4. Sustituir en esta carpeta el DOCX y el PDF anteriores.

El programa enlaza siempre a `Instrucciones_Empuje_Traccion.pdf`.
