# Documentación OCRA

Esta carpeta está pensada para mantener la documentación de uso separada del código del programa.

## Visible para las personas usuarias
- `Instrucciones_OCRA_Una_Tarea.pdf`: PDF que abre el botón **Instrucciones de uso** de OCRA - Una tarea.
- `Instrucciones_OCRA_Una_Tarea.docx`: documento maestro editable.

### Cómo actualizar las instrucciones
1. Editar `Instrucciones_OCRA_Una_Tarea.docx` en Word.
2. Exportarlo a PDF.
3. Sustituir `Instrucciones_OCRA_Una_Tarea.pdf` conservando exactamente ese nombre.
4. No es necesario modificar el programa mientras se mantengan el nombre y la ubicación.

## Información interna
- `INTERNO_Tablas_calculo_OCRA_fuentes_V3_V15_Libro.docx`: comparativa de tablas, criterios y fuentes empleadas en los cálculos.
- Este documento no está enlazado desde la interfaz y no debe mostrarse a las personas usuarias del programa.
